End-to-End Chat Request Flow

1
Step 1: User Prompt Ingestion — Employee submits prompt via Client UI (e.g., "I need a replacement laptop, please check SLA and raise a P1 ticket").
2
Step 2: Security & Authentication Gate — Request is validated by Identity-Aware Proxy (IAP) and sanitized by the Security Shield against prompt injections and FCPA violations.
3
Step 3: Session Context Retrieval — Backend orchestrator fetches employee persona (`EMP1024`), historical session state, and active balances from Firestore.
4
Step 4: GenAI & RAG Execution — Backend dispatches prompt + vector policy context + system instructions to Vertex AI (Gemini 3.1 Pro) and relevant SaaS MCP tools.
5
Step 5: Streaming Response & HITL Governance — Response is streamed back to Client UI. Any state-mutating operation (e.g., P1 ticket creation) renders an interactive HITL card for explicit user sign-off.
