Section 1: 5 Core Design Principles

Comprehensive breakdown of the foundational architectural choices guiding app development.

Principle 01

1. Agentic Architecture

Multi-agent mesh topology featuring a central RootOrchestrator delegating to specialized domain sub-agents:
  • PolicyQAAgent: Vector RAG over 2026 HR/IT handbooks.
  • WorkWeekAgent: Real-time HRMS time-off & profile operations.
  • ServiceImmediatelyAgent: ITSM incident & hardware provisioning.
  • HITL Gate: Human-in-the-Loop cards for stateful mutations.
Principle 02

2. Choice of Runtime

Serverless microservice architecture hosted on Google Cloud Run:
  • Zero Idle Cost: Instant scaling from 0 to peak concurrency.
  • Sub-second Cold Starts: Optimized containerized FastAPI ASGI runtime.
  • Stateless Compute: Decoupled session state offloaded to Cloud Firestore.
  • Dual-Tier Execution: Identical local container dev & Cloud Run deployment.
Principle 03

3. Choice of Conversational UI

Custom Google Gemini Material Aesthetic UI:
  • Zero Reloads: Real-time message streaming with typewriter effect.
  • Persona Switcher: Instant toggle between active employees (EMP1024 / EMP2048).
  • Interactive Cards: Native confirmation cards for HR transactions.
  • Action Chips: Guided prompts for HR policy, leave, & ITSM.
Principle 04

4. System Design on GCP

100% Native Google Cloud Platform stack integration:
  • Vertex AI Gemini 3.1 Pro: Core multi-turn reasoning engine.
  • Agent Gateway: OAuth2 token auth, rate-limiting, and SSE streaming.
  • Cloud Firestore: Session context & state persistence.
  • Cloud Logging & Monitoring: SRE telemetry & audit logs.
Principle 05

5. AI Safety & Governance

3-Stage Active AI Defense via Google Cloud Model Armor & App Shield:
  • Stage 1 (Ingress): Direct prompt injection & PII redaction ([REDACTED_SSN]).
  • Stage 2 (Tool Returns): Indirect prompt injection payload sanitizer.
  • Stage 3 (Egress): Web Risk URL check & grounding verification ($\ge 0.85$).
  • FCPA Guardrails: Active anti-bribery threat filters.

Provides a sleek, responsive conversational interface built with Google Gemini aesthetics. Features zero-reload real-time message streaming, active persona switching between employee profiles (EMP1024 / EMP2048), interactive Human-in-the-Loop (HITL) confirmation cards, and guided quick-action prompt chips.

End-to-End Query Execution Flow (6 Stages)

1
Stage 1: User Query Submission — Employee submits query via Gemini Web UI (e.g., "Book 3 days vacation" or "What is the home monitor policy?").
2
Stage 2: Agent Gateway & Model Armor Ingress Scan — Request passes through Cloud IAP / Agent Gateway. Model Armor Stage 1 inspects for prompt injection, jailbreaks, and redacts PII ([REDACTED_SSN]).
3
Stage 3: Root Orchestrator Context Loading — Cloud Run container receives request, initializes `RootOrchestrator`, and loads active session state from Cloud Firestore.
4
Stage 4: Sub-Agent & RAG Tool Dispatch — `RootOrchestrator` classifies intent and dispatches tasks to sub-agents (`PolicyQAAgent` for RAG vector search over handbook PDFs; `WorkWeekAgent` / `ServiceImmediatelyAgent` for SaaS APIs).
5
Stage 5: Model Armor Tool Sanitization & Gemini Inference — Tool payloads pass Model Armor Stage 2 sanitization before reaching Vertex AI (`Gemini 3.1 Pro`) for grounded reasoning.
6
Stage 6: Grounding Check & Response Delivery — Output undergoes Model Armor Stage 3 grounding validation ($\ge 0.85$) and streams back to client UI, rendering interactive HITL cards if stateful user confirmation is required.
