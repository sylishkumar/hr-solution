Section 1: Design Considerations

Key architectural pillars ensuring enterprise-grade employee usability, safety, and operational scalability.

✨

1. Employee Experience (UX/UI)

  • Fast streaming conversational interface with zero page reloads.
  • Guardrails against off-topic responses, offering guided HR quick-action chips (e.g., Leave Policy, Benefits, Payroll).
  • Glassmorphic floating input dock with active persona switching (`EMP1024` / `EMP2048`).
⚡

2. Serverless & High Availability

  • Built for zero-idle cost and instant cold-start response using containerized microservices.
  • Stateless backend design enabling seamless horizontal auto-scaling from 0 to peak concurrency.
  • Containerized deployment on Google Cloud Run in `us-central1`.
🛡️

3. Security, Privacy & PII Handling

  • Strict enterprise access controls using Identity-Aware Proxy (IAP) & Cloud IAM.
  • Built-in data sanitization to protect sensitive HR/Employee PII with zero model retention.
  • Active FCPA anti-bribery threat filters and expense compliance guardrails.
🧱

4. Extensibility & Agentic Modular Architecture

  • Decoupled agent orchestration enabling easy integration of new tool integrations (e.g., Workday, ServiceNow, internal HR policy databases).
  • Specialized sub-agent mesh (`PolicyQAAgent`, `WorkWeekAgent`, `ServiceImmediatelyAgent`).

End-to-End Chat Flow Sequence

1
Step 1: User Query — Employee submits an HR question via the web interface (port 8000 locally / HTTPS on Cloud Run).
2
Step 2: Authentication & Ingress — Request passes through Cloud Load Balancing / Identity-Aware Proxy (IAP) for user identity validation.
3
Step 3: Agent Processing — Cloud Run container initializes the agent loop, pulling user context and historical session state.
4
Step 4: RAG & Knowledge Retrieval — Agent performs vector lookup against enterprise HR policy knowledge base / database.
5
Step 5: Model Inference — Prompt + retrieved HR policy context + system instructions sent to Vertex AI (Gemini 3.1 Pro model).
6
Step 6: Response Streaming — Agent streams validated, grounded response back to the client while logging session analytics and rendering HITL confirmation cards if required.
