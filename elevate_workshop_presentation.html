Key Architectural & Design Decisions
Core design principles that guarantee enterprise-grade accuracy, security, and operational reliability.
PRINCIPLE 01
Deterministic Policy Grounding vs. Generative Hallucination
Generic LLMs hallucinate leave limits and approval windows. We enforce **zero-hallucination policy grounding** by pairing Gemini 3.1 Pro with a RAG vector engine over official 2026 Altostrat Policy Handbooks, appending exact file anchor citations (`file://...#L10`).
PRINCIPLE 02
Specialized Multi-Agent Mesh Architecture
Rather than relying on a single monolith system prompt, we decompose domain tasks into modular, specialized agents (`PolicyQAAgent`, `WorkWeekAgent`, `ServiceImmediatelyAgent`) governed by a `RootOrchestrator`.
PRINCIPLE 03
Human-in-the-Loop (HITL) Financial & State Governance
Read-only queries (policy questions, balance checks) execute instantly. Any state-mutating operation (booking leave, changing home address, creating ITSM tickets) pauses execution and renders an interactive HITL card requiring explicit employee confirmation.
PRINCIPLE 04
Domain Math & Policy Gotcha Trajectories
Policy edge cases (e.g. shift worker math: 12h shift = 1.5 vacation days; advance notice rules: 7 days required for >2 days leave; TOIL order of operations) are embedded as few-shot trajectory rules to guarantee 100% compliance.
PRINCIPLE 05
Zero-Trust Ethics & FCPA Security Shield
Active Security Shield intercepts prompt injections and prompt leaks while enforcing compliance refusals against FCPA bribery camouflage, personal/gift card reimbursements, and adult venue expenses.
PRINCIPLE 06
State Machine Enforcement for SaaS Integrations
Integrates directly with SaaS APIs (WorkWeek HRMS & ServiceImmediately ITSM) via MCP tools while enforcing state machine transitions (e.g., blocking direct `New` → `Resolved` ticket status jumps).

Working Operational Model & Sequence Execution
How a user request traverses through the Altostrat Agentic Mesh in real time.
STEP 01
Request Ingestion & Persona Context Initialization
The user submits a prompt via the Gemini Web UI (e.g. "I have an issue with my laptop, can you raise a P1 ticket and check SLA?"). The system resolves the active employee persona (`EMP1024` Aish Prabhat) and attaches session context.
STEP 02
Security Shield & Ethics Evaluation
The `RootOrchestrator` runs the prompt through the Security Shield. If prompt injection, prompt leak, or illegal expense requests (bribery, gift cards, adult venues) are detected, an immediate grounded refusal is returned without hitting sub-agent tools.
STEP 03
Intent Classification & Trajectory Matching
The prompt is evaluated against 10 specialized Policy Gotcha Trajectories. The orchestrator delegates execution to the appropriate sub-agent (`ServiceImmediatelyAgent` for IT issues, `WorkWeekAgent` for leave/profile, `PolicyQAAgent` for handbooks).
STEP 04
SaaS MCP Tool Execution & SLA Calculation
The sub-agent executes necessary SaaS MCP tools (e.g., querying WorkWeek for leave balances or calculating ServiceImmediately SLA response time: P1 = 15 mins response, 2-hour resolution window).
STEP 05
HITL Card Generation / Grounded Response Output
If the action modifies state, the system renders an interactive `HITL_REQUIRED` confirmation card on the front-end with action parameters (`Priority: 1 - Critical`, `Category: Hardware`). Upon user clicking "Confirm & Submit", the mutation is executed safely.
